## 3. ANIMATIONS & EFFECTS

### SCROLL ANIMATIONS

**On-Scroll Fade-Ins:**
- Elements start with: `opacity: 0`
- Animate to: `opacity: 1`
- Common pattern: `opacity:0;transform:translateY(30px) scale(0.8)`
- Elements fade in and slide up as user scrolls

**Hero Elements:**
- Badge: `translateY(-20px) scale(0.95)` → normal
- Heading: `translateY(30px) scale(0.8)` → normal
- Subheading: `translateY(30px) scale(0.8)` → normal
- Button: `translateY(30px) scale(0.8)` → normal

**Phone Mockups:**
- Initial: `opacity:0.001; transform:translateY(60px) scale(0.8)`
- Final: `opacity:1; transform:translateY(0) scale(1)`

**Counter Animations:**
- Stats section numbers animate from 0 to final value
- Number format: Counting up effect (450, 150, 50)

## SUMMARY

The Appit website is a **modern, dark-themed social app landing page** built with Framer. It uses a **black background** with **white text**, **large typography** (64px hero), and **multiple phone mockups** with 3D perspective effects. The design features **scroll-based animations** (fade-ins, slide-ups), **responsive grids** (1-4 columns), and **generous spacing** (60-175px padding).

Key fonts are **Inter Tight** (headings) and **Instrument Sans** (body), with **line heights of 120-150%**. The site includes **7 main sections**: Hero, Stats, Benefits, Features, Testimonials, FAQ, and CTA. Buttons are **rounded** (12px radius) with **white backgrounds**, and cards have **24px radius** on **dark gray backgrounds** (#0e0e10).

Mobile breakpoint is **809px**, with font sizes reducing from **64px to 34px** for H1. Phone mockups use **3D transforms** (rotate, skew) and appear throughout the page. The design emphasizes **authentic connections**, **global reach**, and **personalized experiences** through clean, modern UI patterns.
